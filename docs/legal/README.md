# Legal document placeholders

Do not publish generic generated legal text as if it were approved. Before a commercial launch, counsel must provide jurisdiction-specific:

- Terms of Service;
- Privacy Policy;
- Cookie/analytics disclosure if the buyer adds non-essential tracking;
- acceptable-use and abuse rules;
- refund/subscription terms if billing is introduced;
- data-processing and subprocessors disclosures where applicable.

Set `VITE_TERMS_URL`, `VITE_PRIVACY_URL` and `VITE_SUPPORT_URL` only after the final documents and support channel exist.
