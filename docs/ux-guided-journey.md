# Guided learner journey

## Information architecture

### Persistent navigation

1. **Today** — one recommended action, current weekly contract and immediate review debt.
2. **My plan** — the complete adaptive route and evidence graph.
3. **Learn** — lessons and projects in the recommended sequence.
4. **Practice** — the SQL workspace.
5. **Review** — due retrieval practice.

### All tools

The following specialist surfaces remain available in one collapsed disclosure instead of competing in the permanent navigation:

- full task catalog;
- interview mode;
- assessments;
- checkpoints;
- syllabus and dialect labs;
- puzzles;
- achievements;
- AI mentor;
- personal learning analytics.

## First-run contract

A newly authenticated account automatically enters onboarding once per browser session until the profile is complete. The learner chooses:

- desired outcome;
- sustainable session length and study days;
- experience level;
- executable placement or a clearly labelled temporary deferral.

The product then produces a first-week plan and returns the learner to **Today**.

## Returning learner contract

The Today screen derives one next action in this order:

1. overdue retrieval review;
2. first incomplete task in a placement focus module;
3. first incomplete task in the recommended route;
4. the last open task when it is still incomplete.

The learner may inspect advanced tools, but the product never requires understanding their internal names to continue learning.
