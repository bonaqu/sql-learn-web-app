# Complete lesson loop v3

## Учебный контракт

Все 44 урока нельзя пройти чтением и ручными отметками. Перед прогнозом показана модель темы; в первом уроке отдельно объяснены SQL, база, таблица, строка, столбец, NULL и SELECT/FROM на фрагменте настоящих учебных данных. Затем ученик фиксирует прогноз, запускает и меняет SQL на локальном SQLite и дополняет запрос с сокращённой подсказкой. Ошибка связывается с конкретным расхождением, контрпримером и точкой возврата.

Шаги последовательны: рабочий пример скрыт до прогноза, сокращённая практика — до успешного запуска примера, продолжение — до семантически верной практики. Кнопка продолжения сначала переводит фокус к обязательным вопросам понимания. После вопросов она использует единый маршрут: доступная задача с опорой, самостоятельная практика или контрольная точка. Редакторские puzzle-задачи из таблицы ниже являются будущим переносом после контрольной точки фазы, а не немедленной кнопкой после урока. Условия доступа не ослаблены. Чтение раздела и SQL с опорой не создают самостоятельное освоение.

Проверка первого пути больше не ограничивается видимостью строки task-006: браузер отвечает на вопросы, открывает task-001, выполняет SQL без подсказок и переходит к доступной task-002. На мобильном панель связи уроков находится после материала, а не поверх него.

Пояснения о таблице, строках и столбцах сверены с [PostgreSQL: Concepts](https://www.postgresql.org/docs/current/tutorial-concepts.html), разбор SELECT/FROM — с [PostgreSQL: Querying a Table](https://www.postgresql.org/docs/current/tutorial-select.html) и [SQLite: SELECT](https://www.sqlite.org/lang_select.html). Текст и пример написаны для собственного учебного набора; данные фрагмента дополнительно сравниваются с исполнением настоящего seed в валидаторе.

## Полная карта 44 уроков

- 20 core-уроков используют весь авторский блок из 6 задач: первая lesson-задача даёт опору, четвёртая задача становится сокращённой практикой, последняя puzzle-задача — самостоятельным переносом.
- 24 advanced-урока делят 120 advanced-задач на непересекающиеся блоки по 5: первая lesson-задача даёт опору, третья practice-задача — сокращённую практику, пятая puzzle-задача — перенос.
- Три вводных цикла сохраняют вручную отредактированные прогнозы, контрпримеры и визуальные модели. Остальные 41 используют уже отредактированные objectives, checks, runnable examples, task descriptions и task contracts; SQL-заготовка создаётся из авторского starter или из явно выбранного смыслового фрагмента решения.
- `scripts/validate-beginner-lesson-loop.ts` доказывает 44/44 lesson cycles и 240/240 task IDs без пропусков и повторов. Для каждого урока он удаляет по одному обязательному этапу и требует падения проверки, запускает канонический SQL и отклоняет отдельный неверный запрос.

Core-сокращение проверяется по форме, строкам, NULL, значениям и порядку на base + hidden/adversarial fixtures. Каждый advanced-скрипт связан со своим versioned contract: evaluator сравнивает результат и временное состояние отдельной SQLite-базы. Для 117 лабораторий два дополнительных набора меняют входные данные до выполнения логики, включая DML; три задачи с фиксированными входами (`task-141`, `task-171`, `task-229`) проверяют только объявленный публичный контракт. Ограничения схемы проверяются допустимыми и запрещёнными записями, а не наличием ключевых слов. Валидатор отклоняет 115 подставленных публичных ответов, пять DML-мутантов, верных только на видимых данных, и шесть схем с пропущенными ограничениями; пять альтернативных решений принимаются. Во всех 44 циклах faded, supported и independent task различаются.

## Визуальные модели

- SQL-мышление: повторяющиеся значения сервиса и отдельный контракт порядка.
- Фильтрация: решение по каждой строке и отдельное состояние UNKNOWN для NULL.
- SELECT: форма строки до и после вычисляемого столбца.

Каждая таблица имеет `caption`, заголовки столбцов и текстовое решение для строки; цвет остаётся дополнительным сигналом.

## Маршрут урока

1. Открыть первый урок без предварительных знаний.
2. Выбрать прогноз; пример до этого скрыт.
3. Получить объяснение расхождения или подтверждение.
4. Изменить и выполнить пример локально.
5. Заполнить пропуск и выполнить сокращённое упражнение.
6. При ошибке открыть точечное объяснение и контрпример.
7. Только после верной сокращённой практики открыть задачу с опорой или отдельную puzzle-задачу без раскрытого решения.
8. После самостоятельного решения увидеть следующий обязательный шаг и отложенное повторение.

## Офлайн и доступность

Все SQL-примеры используют bundled `sql-wasm.wasm` через общий `src/lib/sql-browser.ts`; сетевой CDN в учебном потоке не нужен. Нативные `fieldset`, `legend`, radio, `details`, таблицы и кнопки поддерживают клавиатуру и экранные дикторы. Цели нажатия не меньше 44 px, узкие экраны получают одноколоночные действия, а анимации учитывают `prefers-reduced-motion`.

Browser evidence находится в `tests/e2e/lesson-continuity.spec.ts`: desktop-тест открывает все 44 урока и проверяет gates/отсутствие ручных отметок, затем реально выполняет advanced DML example, canonical faded SQL и переход к task-125. В том же файле выполняются desktop offline SQL, mobile layout, axe и continuity checks.
